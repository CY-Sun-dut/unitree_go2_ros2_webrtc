# go2_webrtc_test — GO2 测试程序包

`go2_webrtc_ros2` 的配套测试工具（主包不含测试代码）。前置：`go2_cmd.launch.py`
或 `go2_all.launch.py` 已启动（bridge + 指令节点在线）。

## 1. keyboard_teleop —— 键盘遥控测试

```bash
ros2 run go2_webrtc_test keyboard_teleop     # 独立终端
```

**流程：先按 `u` 解锁，再按移动键。**

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| `u` | 解锁 enable | `l` | 锁定 disable（含停止帧） |
| `w`/`s` | 前进/后退 | `a`/`d` | 左移/右移 |
| `q`/`e` | 逆时针/顺时针旋转 | `空格` | 急停（停止帧） |
| `1` | 站立 stand_up | `2` | 趴下 stand_down |
| `3` | 平衡站立 balance_stand | `4` | 恢复站立 recovery_stand |
| `5` | 阻尼 damp | `6` | 坐下 sit |
| `7` | 坐姿站起 rise_sit | `0` | 停止移动 stop |
| `Ctrl+C` | 退出（自动停止帧） | | |

- 界面：帮助区固定；底部两行原地刷新（状态行 + 最新指令行，含服务返回码）；
- 移动键松开 0.5s 自动停止；默认速度 0.15 m/s（`speed` 参数）、旋转 0.25 rad/s（`turn_speed`）；
- 未解锁时移动键会被拦截并提示。

## 2. cmd_console —— 菜单式功能测试控制台

```bash
ros2 run go2_webrtc_test cmd_console
```

主菜单 6 类，逐条执行并显示 SDK 返回码（`✔/✘ code=...`）：

| 菜单 | 覆盖内容 |
|---|---|
| [1] 移动类 | 解锁/锁定、发送 vel / vel_avoid（持续 1s 后自动停止帧） |
| [2] 状态转换 | 8 个状态服务（站立/趴下/平衡站立/恢复/阻尼/坐下/坐起/停止） |
| [3] 姿态/参数 | Euler 姿态、机身高度、抬腿高度、速度档 1-3、步态 id、避障/连续步态/遥控器/Pose/StandOut 开关、避障查询 |
| [4] 模式切换 | normal/ai/mcf 切换、任意模式名、查询模式/速度档/运动状态 |
| [5] 动作类 | 19 个动作服务（含 ⚠高动态）+ action_id 直通口 |
| [6] 灯光/音量 | 音量 0-10、亮度 0-10、灯色（7 色）、查询 |

## 3. 安全提示

- 测试移动前：狗放地面开阔处、遥控器在手；先 `damp`/`stand_down` 等安全状态起步；
- 移动默认幅度小（0.15 m/s），`cmd_console` 发 vel 前留意提示；
- ⚠ 高动态动作（空翻/倒立等）务必开阔场地、风险自负；
- 任何时刻：键盘 `空格` 急停 / `l` 锁定 / 遥控器急停。
